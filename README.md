# Home SOC Lab

Cybersecurity project focused on building and documenting a Security Operations Center (SOC) environment using Wazuh, Windows, Linux, and Sysmon.

## Detection Scenarios

Hands-on security detection scenarios developed, tested, and documented in the SOC lab.

| ID | Detection Scenario | Status |
|---|---|---|
| 001 | [Failed Windows Logon Detection](detections/001-failed-windows-logon/) | Completed |
| 002 | [PowerShell Execution Monitoring](detections/002-powershell-execution-monitoring/) | Completed |

Each scenario includes technical analysis, detection evidence, and documented validation results.

## Project Goals
- Deploy and configure a centralized security monitoring platform.
- Collect and analyze Windows and Linux security events.
- Develop practical threat detection scenarios.
- Investigate security alerts and document findings.
- Practice incident response workflows.

## Planned Technology Stack
- Wazuh SIEM/XDR
- Ubuntu Server
- Windows and Sysmon
- VirtualBox
- Linux

## Project Status
Planning and environment preparation.

## Disclaimer
All security testing will be performed in an isolated, authorized laboratory environment.
