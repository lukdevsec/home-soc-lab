# Home SOC Lab

A hands-on cybersecurity project focused on building and documenting a Security Operations Center (SOC) environment using Wazuh, Windows, Linux, and Sysmon.

## Project Goals
- Deploy and configure a centralized security monitoring platform.
- Collect and analyze Windows and Linux security events.
- Develop practical threat detection scenarios.
- Investigate security alerts and document findings.
- Practice incident response workflows.

## Planned Technology Stack
- Wazuh SIEM/XDR
- Ubuntu Server
- Windows and Sysmon
- VirtualBox
- Linux

## Project Status
Planning and environment preparation.

## Disclaimer
All security testing will be performed in an isolated, authorized laboratory environment.
